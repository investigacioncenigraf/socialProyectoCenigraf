# Press Start 2P

Fuente oficial: https://github.com/google/fonts/tree/main/ofl/pressstart2p

Se conserva PressStart2P-Regular.ttf con su licencia OFL y FONTLOG. PressStart2P SDF.asset contiene el atlas/material de TextMeshPro, con atlas estático precalculado para caracteres latinos y españoles, acentos y símbolos de interfaz.

Es la fuente predeterminada de TMP Settings y está aplicada a los textos existentes de escenas/prefabs. Los textos creados por código mediante TMP_Settings.defaultFontAsset también la utilizan.
